# Antrian Klinik

Aplikasi Antrian Klinik Sederhana  
Dibuat menggunakan React + Vite untuk latihan pengembangan web frontend.

---

## 📌 Deskripsi

Project ini adalah aplikasi web sederhana untuk mengelola antrian pasien di sebuah klinik.  
Fitur utamanya:
- Menambahkan data pasien ke daftar antrian
- Mengubah status antrian (diproses, selesai)
- Menghapus data antrian
- Menampilkan daftar antrian secara dinamis

---

## ⚙️ Stack & Teknologi

- **React**
- **Vite**
- **JavaScript** 
- **CSS Modules** 

---

## 💡 Tujuan Pembuatan

Project ini dibuat untuk:
- Menerapkan konsep CRUD sederhana di React
- Belajar state management dasar dengan React `useState` / `useContext` 
- Mendokumentasikan hasil belajar di GitHub
